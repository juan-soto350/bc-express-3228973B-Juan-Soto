# Mis Entregas - Trimestre 5 (SENA)

Repositorio centralizado para el desarrollo de actividades y proyectos de la formación.

## 📂 Organización del Repositorio

Las actividades están divididas por ramas específicas para mantener el código limpio y ordenado:

* **[Semana 01](./../../tree/week-01)**: Introducción, configuración del entorno y primeros pasos con Express.
* **[Semana 02](./../../tree/week-02)**: Desarrollo de rutas, controladores y estructura del proyecto.
* **[Semana 03](./../../tree/week-03)**: Desarrollo de API REST en capas del dominio Arcade.
* **[Semana 04](./../../tree/week-04)**: Desarrollo de validación con Zod, AppError y logging Winston.
* **[Semana 05](./../../tree/week-05)**: Desarrollo de API PostgreSQL + Prisma ORM del dominio Arcade.
* **[Semana 06](./../../tree/week-06)**: Desarrollo de API MongoDB + Mongoose del dominio Arcade
